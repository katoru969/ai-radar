# YouTubeの収集方針（2026-10-13）

ユーザーの希望に合わせ、初歩的な使い方の基礎講座から、実務の活用・新機能・AIの動向・仕事や社会への影響へ重点を移しました。エンジニア向けの実装や環境構築は引き続き対象外です。モデル名が出るだけの動画を無条件に掲載する仕組みではありません。

## 動画の選別

- 優先：ChatGPT・Claude・Gemini等の新機能、利用条件、何に課金するか、具体的な仕事術、比較、AIニュースと動向、AIと仕事・社会・安全性の議論。
- 除外：超初心者・ゼロから・基礎的な操作講座、実装・CLI・API開発・環境構築、AIの関連がタイトルから確認できない政治動画、株式・投資信託・スポーツ、募集や宣伝だけの回。
- 「脱初心者」の応用、簡単な設定、コード不要・コピー程度の手順は対象。ニュースのまとめで一部にCodexが登場するだけなら、実装講座と同じ扱いにはしません。
- チャンネル名だけで重要度Aへ引き上げません。新しさ・用途・利用条件を優先し、理解済みの記事はTodayに戻しません。

RSS/公開ページを使う無料方式で、検索API・YouTube Data APIのキーは不要です。通常はRSSを優先し、RSSの障害時は公開ページで復旧します。多投稿の媒体はRSS成功時にも公開一覧を確認して、RSSの最新15本から押し出されたAI回を補います。全履歴の検索や毎回必ず各チャンネル1本を掲載する保証はありません。

mikimiki webスクールの収集先は削除しました。以前に保存したブックマークと確認済み編集メモは残します。新たな動画の実演内容は字幕等が確認できた範囲だけを表示し、説明欄・章タイトルだけからハンズオンを作りません。

説明欄の特典・新刊・イベント告知・出演者プロフィールをまとめに使わないよう除外します。本文がなく章名だけの場合は「説明欄のテーマ」と明記し、詳しい結論や実演は未確認と表示します。説明・章とも確認できない動画は、読める別の候補があるときにTodayの件数合わせへ使いません。新規チャンネルを加えても、全動画の字幕を安定して取得できるようになったわけではありません。
