# YouTubeの詳しいまとめ / 2026-10-13

## 今回確認した原因

公開データ47動画のうち42動画は詳細が空。直接取得は1回10動画までで、失敗結果も24時間再利用していました。KEITOのMods、AI仙人のdots、安野貴博のAI活用レポートには公開ページに日本語字幕トラックがありましたが、字幕URLへのHTTP 200応答の本文は空でした。したがって「動画に字幕がない」とは言えません。

YouTube側の字幕配信条件による空応答は[字幕取得ライブラリの報告](https://github.com/jdepoix/youtube-transcript-api/issues/592)にもあります。公式の[字幕ダウンロードAPI](https://developers.google.com/youtube/v3/docs/captions/download)は編集権限が必要です。一般視聴者のAPIキーを追加するだけでは解決しません。

## 無料で行う取得

1. 公開ページの日本語字幕を直接取得。Today候補に多くの枠を割き、その他は前回の試行日時が古い順に回す。1収集12動画まで。
2. GitHub Actionsでは通常のChromiumで説明欄の[「文字起こしを表示」](https://support.google.com/youtube/answer/15930243?hl=ja)を開き、公開パネルの日本語文と時刻を読む。最大8動画・90秒。APIキー、ユーザーのログイン情報、プロキシは使わない。認証やCAPTCHAが必要なら失敗を隔離してニュースを公開する。
3. 読めた字幕から要点・詳細・具体例を抽出。短すぎる字幕や章名だけでは詳しいまとめを生成しない。字幕原文、署名付きURL、Cookieは公開JSON・ログへ保存しない。
4. 内容を確認して書き直した動画は `content/video-guides.json` の編集メモを使う。動画ID・発信元・原題を照合。複数言語の原題は確認済みの別表記だけ許可し、別動画へ流用しない。

直接取得の失敗キャッシュは2時間、確認済みのまとめは同じ原題・説明欄・処理バージョンなら30日保存。ブラウザーの再試行は3時間以上あけ、失敗しても他の動画を次回試せる構造です。

Todayは30日以内に140字以上の詳細が10件あれば、その記事から10件を選びます。直近7日を優先し、件数が足りる場合は詳しい内容が空の動画をTodayの枠へ入れません。理解済み・情報源OFFは先に除外。未取得の動画もExploreには残り、元動画やチャプターから確認できます。

## 限界

- ブラウザー経由でもYouTubeや実行環境により取得できない動画があります。全動画の自動要約を保証するものではありません。
- 課金AI APIは未接続。自動処理は抽出方式で、自然な日本語への書き直しは編集メモのある動画だけです。
- 自動字幕の誤認識や映像にだけ表示される説明は確認できません。章名から手順や結果を補いません。
- ブラウザーはGitHub Actionsの追加処理です。Vercel/API版では従来の直接取得と編集メモを利用します。ローカル補完用は `node scripts/collect-video-captions.mjs`（Chromiumの導入が必要）。

ブラウザーの導入は[Playwright公式CI手順](https://playwright.dev/docs/ci)に従います。依存はnpmの公式パッケージで固定し、ブラウザー処理が失敗しても通常のニュース公開を続けます。
